The Problem We Solve

"Criminals do not get caught because Tor fails. They get caught because human operational security (OPSEC) fails."

Dark web operators believe they are invisible

  • They use Tor to hide their location
  • They use fake usernames that change per site
  • They use cryptocurrency instead of bank accounts
  • They use encrypted messaging for communication

But humans leave patterns

  • They reuse encryption keys and wallet addresses
  • They write with the same grammar and quirks
  • They sleep at the same hours every night
  • Their servers leak real-world clues

🏴‍☠️ Silk Road — Ross Ulbricht

Used his real email rossulbricht@gmail.com to promote the site. PGP key tagged with laptop username frosty. Server leaked its real IP.

🏴 AlphaBay — Alexandre Cazes

Welcome emails contained pimp_alex_91@hotmail.com. Reused handle "Alpha02" across forums. Consolidated crypto wallets.

🔄 Hansa, Wall Street, Darkode

Shared TLS certs, Favicon hashes, server banners, and identical posting-hour distributions across migrations.

Five-Layer Architecture

🔭
Layer 1 — Collection
Crawl dark web sites through Tor. Lab hidden service for testing with real Tor circuits. Rate-limited: 1 req / 2s.
🔬
Layer 2 — Extraction
BTC/ETH/XMR wallets (checksum-verified), PGP fingerprints, emails, Telegram, Jabber. Leet-speak decode: Dr3adPirat3 → dreadpirate.
🔎
Layer 3 — Reconnaissance
Passive server fingerprinting: HTTP headers, ETag, favicon mmh3 hash, TLS cert SANs, /server-status leaks. Clearnet correlation via Shodan.
🧩
Layer 4 — Linking
Stylometry (TF-IDF writeprints), 24h posting-hour histogram, trade vocabulary Jaccard, network graph, cluster resolution.
📊
Layer 5 — Scoring & Output
Weighted formula → confidence bands. Dashboard, live paste analysis, PDF dossier, CSV/JSON export. Full audit log.

What the System Refuses to Do

A tool that only says "yes" is a tool that's guessing

📄

Too Little Text

Account "paperghost" has only 152 characters. The floor is 300.

→ Stylometry returns NOT ASSESSED

Rather than guessing from two sentences, the weight is redistributed to what can be measured.

💰

Invalid Wallets

"CryoVault" posted a Bitcoin address that fails Base58Check.

→ Address is DROPPED, never stored

A regex-only match on hex strings would link everyone to everyone. Checksum validation prevents phantom links.

👥

Look-Alikes

"NordicPharm" and "AtlasMeds" write in a similar formal style.

→ Score: WEAK — 0.242

Different posting hours (0.08 overlap) and different misspellings. Correctly recognized as distinct actors.

🧪 Buyer Trust Signal — Measured, then Rejected

Shared buyer reviews yield ROC-AUC 0.389 — worse than a coin flip. Wrong pairs score higher because buyers shop around. Shown as dashed lines on the graph, never added to the score.

How It Works

  • Paste any text — a news article, vendor bio, anything
  • Text is vectorized against the stored vocabulary (no refit)
  • Compared against all 20 stored writing profiles
  • Scored using the exact same formula as batch mode
