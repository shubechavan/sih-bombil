# requirements.txt — everything Dark Sentinel v2 actually imports.
#
# The GLiNER / HuggingFace stack is NOT here. It lives in requirements-ml.txt
# because nothing in v2 imports it directly: extract/gliner_extract.py loads the
# model dynamically through legacy/llm.py and falls back to the regex extractor
# when it is absent, which is the path the fixture corpus and every test use.
# Installing it pulls PyTorch — roughly 3 GB — for code the demo never executes,
# so the container image and a fresh `pip install` do not pay for it.
#
#   pip install -r requirements.txt        # pipeline, API, reports, tests
#   pip install -r requirements-ml.txt     # adds GLiNER-backed entity extraction
